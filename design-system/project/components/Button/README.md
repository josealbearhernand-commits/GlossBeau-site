# Button

The pill button; the variant says how important the action is.

- `primary`: accent fill, dark label, tinted shadow. One per view.
- `secondary`: white with a hairline and soft shadow.
- `light`: white, for photos and dark tiles. `dark`: ink-deep fill.
- `size="sm"`: 36px, 14px semibold label.
- Provide `children` (a verb first), optional `href`, `iconAfter`.
