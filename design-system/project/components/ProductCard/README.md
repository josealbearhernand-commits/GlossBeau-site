# ProductCard

28px white card with the dual shadow; the photo sits in a 20px frame 8px in, so every product keeps a thin white border.

- Provide from the Storefront API: `title`, `image`, `vendor`, `price`, `compareAtPrice`, `soldOut`, `href`.
- Hover lifts the card, scales the photo 5% and reveals the round accent add button.
- Mockups without a photo show the "Product photo from Shopify" slot, never a stock image.
